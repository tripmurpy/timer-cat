# Panduan Pengguna Cute Timer

Cute Timer membantu Anda mengatur waktu belajar atau bekerja dari desktop Windows. Anda bisa memilih tampilan besar, ringkas, atau sangat kecil tanpa menghentikan hitungan waktu.

## Mulai dalam 1 menit

1. Klik dua kali shortcut **Cute Timer** di Desktop.
2. Klik **+10 MENIT**, **+15 MENIT**, atau **+20 MENIT**. Anda boleh menekan tombol beberapa kali untuk menambah durasi.
3. Klik **START** untuk memulai hitungan mundur.
4. Klik **PAUSE** jika ingin berhenti sejenak.
5. Klik **RESET** untuk menghapus waktu dan kembali ke `00:00`.

Timer tidak akan berjalan sebelum Anda menambahkan waktu. Durasi paling lama adalah 1 jam 25 menit.

## Tampilan Full

![Tampilan Full Cute Timer dengan waktu 35 menit](images/timer-full.png)

Tampilan Full memuat seluruh kontrol. Capture di atas menunjukkan waktu `35:00` dalam keadaan **JEDA**.

- Angka besar di tengah menunjukkan sisa waktu.
- Kucing berjalan menjadi hiasan selama Anda memakai timer.
- **START** memulai hitungan mundur.
- **PAUSE** menghentikan hitungan sementara tanpa menghapus sisa waktu.
- **RESET** mengembalikan waktu ke `00:00`.
- **+10 MENIT**, **+15 MENIT**, dan **+20 MENIT** menambah durasi.
- **MICRO** dan **COMPACT** mengganti ukuran tampilan.

Status di bawah timer memberi tahu keadaan aplikasi:

- **SIAP**: belum ada waktu yang berjalan.
- **BERJALAN**: waktu sedang berkurang.
- **JEDA**: waktu sedang dihentikan sementara.
- **FINISH**: waktu sudah habis.

## Tampilan Compact

![Tampilan Compact Cute Timer dengan waktu 35 menit](images/timer-compact.png)

Tampilan Compact hanya menunjukkan sisa waktu dan kucing. Mode ini cocok saat Anda masih ingin melihat timer tanpa menutupi banyak bagian layar. Jendela Compact tetap berada di atas aplikasi lain.

Cara memakai Compact:

- Klik **COMPACT** dari tampilan Full.
- Klik dua kali pada area timer untuk menjeda atau melanjutkan.
- Klik tiga kali pada sisi kiri untuk mengurangi 10 menit.
- Klik tiga kali pada sisi kanan untuk menambah 10 menit.
- Besarkan jendela untuk kembali ke tampilan Full.

Saat klik dua atau tiga kali berhasil, timer menampilkan tulisan singkat seperti `STOP`, `PLAY`, `−10`, atau `+10`.

## Tampilan Micro

![Tampilan Micro Cute Timer dengan waktu 35 menit](images/timer-micro.png)

Micro adalah tampilan paling kecil. Capture di atas menunjukkan empat bagian: tombol `×`, pegangan titik-titik, sisa waktu, dan kucing di dalam roda. Jendela Micro tidak memakai bilah judul dan tetap berada di atas aplikasi lain.

Cara memakai Micro:

- Klik **MICRO** dari tampilan Full, atau tekan `M`.
- Tarik pegangan titik-titik untuk memindahkan timer.
- Klik `×` atau tekan `M` untuk kembali ke Compact. Tombol `×` tidak menutup aplikasi.
- Klik dua kali pada area timer untuk menjeda atau melanjutkan.
- Klik tiga kali pada sisi kiri atau kanan untuk mengurangi atau menambah 10 menit.

## Shortcut keyboard

Klik jendela Cute Timer lebih dahulu, lalu gunakan tombol berikut.

| Tombol | Fungsi |
|---|---|
| `Space` | Memulai timer |
| `P` | Menjeda timer |
| `R` | Menghapus waktu dan kembali ke `00:00` |
| `A` | Membuka menu tambah waktu |
| `1` | Menambah 10 menit |
| `2` | Menambah 15 menit |
| `3` | Menambah 20 menit |
| `M` | Membuka Micro atau kembali ke Compact |
| `H` | Membuka bantuan |
| `Q` | Menutup Cute Timer |

## Saat waktu habis

Timer berhenti di `00:00` dan Windows membunyikan suara selesai. Tampilan Full menunjukkan status **FINISH**. Pada Compact, angka berganti sementara menjadi animasi kucing dan percikan kecil.

## Jika timer terasa tidak bekerja

- **START tidak bereaksi:** tambahkan waktu terlebih dahulu.
- **Tampilan terlalu kecil:** tekan `M` atau klik `×` untuk kembali ke Compact, lalu besarkan jendela jika ingin membuka Full.
- **Shortcut tidak bereaksi:** klik jendela Cute Timer, lalu tekan shortcut lagi.
- **Suara selesai tidak terdengar:** periksa volume Windows.

Untuk membuka aplikasi tanpa shortcut Desktop, ketik `timer` melalui terminal Windows setelah Cute Timer dipasang.
